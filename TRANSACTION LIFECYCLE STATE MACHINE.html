2. State Configuration Matrix

State ID Phase Designation Active Timers Transition Trigger Automated Action / Ledger Command
STATE 01 Initialization & Funding None Buyer authorizes deposit via Open Banking API. Funds are locked in Partner Bank escrow nodal account. Initializes State 02.
STATE 02 Pre-Fulfillment Guard Delivery Timer (TR_DELIVERY) Fulfillment Webhook OR Timeout Expiration. If fulfilled, ignites State 03. If timeout occurs, automatically reverts 100% of funds to buyer (Auto-Cancel).
STATE 03 Post-Fulfillment Verification Inspection Timer (TR_INSPECTION)
Rejection Timer		 Buyer explicitly approves, Inspection expires, OR Buyer objects. If approved/expires, ignites State 04. If objected, freezes ledger and shifts to State 05 (Dispute).
STATE 05 Dispute Triage (Tiers 1-3) Arbitration Timers (T1/T2) Mutual resolution OR Admin default ruling. Executes split, refund, or release payload to Partner Bank API based on final case resolution.
STATE 04 Final Settlement Payment Timer (TR_PAYMENT) Receipt of clear instructions from State 03 or State 05. Immediate API payload dispatch to clear funds to the verified seller account. Closes contract loop.
